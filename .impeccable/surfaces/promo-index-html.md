# Social videos: what fontsecret does

Scope: three 6-second social videos, 1080×1350 (4:5), 30 fps, rendered from `promo/index.html`. Visitor mode: Persuade. Audience: developers who stream, share screens and post terminal screenshots. Action: remember the name `fontsecret` and what it does. Proof: the real patched Cascadia Code shaping live in Chrome (HarfBuzz); no simulated masking. Constraint: never overclaim (pixels, not text). Unattended run: direction assigned by the roll, not chosen by the user.

## Direction contract

THESIS: A font is a set of metal sorts; `fontsecret` swaps a secret's sorts for a dot as they are set. Each video is one press proof pulled in two inks, not a terminal screen recording with captions on top.

OWN-WORLD: Letterpress poster proof. Fluorescent orange stock, one blue-black ink, no grays (Riley gallery raise: two tones only, density from texture). Ink has grain and uneven coverage (hard-edged voids of bare stock); no deboss, because it can't be drawn in two tones without reading as a shadow; display set in Big Shoulders (Chicago wood type) at poster scale, code set in the real Cascadia Code.

STORY: (A) a token streams in and every frame stays masked; (B) the same `.env`, one roller pass, the secrets go to dots; (C) copy it and the paste holds the real key: it hides pixels, not text.

FIRST VIEWPORT: Full-bleed stock. A wood-type headline stamped across the top third; the code line at 56–64 px Cascadia Code across the middle, the hero; a frame counter as a printer's slug at the foot; `fontsecret` lockup stamped in the last second.

FORM: candidate 6 of 7 (letterpress composing room), seed:33ee134c8822dc06. Raises: frame counter as a mark of state (cutting-bench raise: state is a mark, not a hue); one focal hub per video (title-card raise).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
